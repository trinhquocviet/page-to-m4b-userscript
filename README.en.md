# Page to M4B Userscript

[![Release](https://img.shields.io/github/v/release/trinhquocviet/page-to-m4b-userscript?style=for-the-badge&logo=github)](https://github.com/trinhquocviet/page-to-m4b-userscript/releases/latest)
[![Install Userscript](https://img.shields.io/badge/Install-Userscript-10b981?style=for-the-badge&logo=tampermonkey)](https://github.com/trinhquocviet/page-to-m4b-userscript/releases/latest/download/page-to-m4b.user.js)

A userscript that automatically injects a quick conversion button into supported audiobook websites, allowing you to extract and package audiobooks into chaptered `.m4b` files with a single click directly in your browser.

---

## Installation Guide

1. Install a userscript manager browser extension: [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Click the link: **[Install page-to-m4b.user.js](https://github.com/trinhquocviet/page-to-m4b-userscript/releases/latest/download/page-to-m4b.user.js)**.
3. When the extension installation prompt appears, click **Install** to complete.

## Supported Websites

- **Radio Sách** (`radiosach.com`)
- **Radio Ngôn Tình** (`radiongontinh.com`)
- **AudioAZ** (`audioaz.com`)
- **Dilib / Thư Viện Sách Nói** (`dilib.vn`, `thuviensachnoi.vn`)

## Automatic Updates

The script is pre-configured with `@updateURL` and `@downloadURL` directives linking directly to this repository's GitHub Releases. Your userscript manager will automatically detect and install new updates as soon as they are published.
